# Images

Drop the restaurant interior photo here as:

    images/interior.jpg

It's referenced by `.interior-photo` in `css/style.css` (the section at the
bottom of the home page) and will show up automatically — no other changes
needed. If you'd rather use a `.png` or `.webp`, just update that one
`background-image` path in the CSS to match.

Drop the logo mark here as:

    images/logo.png

It's referenced directly in `index.html` (the hero `<img class="hero-logo-img">`)
and will show up automatically once it's added. A version with a transparent
background will blend into the page better than one with a white square
behind it, but it'll work either way.
